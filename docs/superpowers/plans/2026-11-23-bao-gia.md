# Soạn báo giá chương trình — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sale soạn báo giá chương trình (1 hoặc nhiều phương án nơi ở) trên web, gửi khách link `baogia.vivatrip.vn/bg/<mã>` đẹp + PDF A4 in từ trình duyệt.

**Architecture:** Bảng `quotes` (jsonb cho phương án/dòng dịch vụ), RLS khoá hoàn toàn, mọi đọc/ghi qua API route dùng service role. Logic tính tiền, sinh mã, kiểm tra dữ liệu, điền từ kho là module thuần trong `lib/quote-*.ts` (test bằng `node --test`). Middleware: chặn `/bao-gia` + `/api/quotes` bằng mật khẩu chung sale, và trên host `baogia.vivatrip.vn` chỉ mở `/bg/*`. Một component `QuoteDocument` dùng chung cho xem trước trong trình soạn và trang khách; PDF = `window.print()` + CSS in A4.

**Tech Stack:** Next.js 15 App Router, React 18, TypeScript, Tailwind 3, Supabase (`@supabase/supabase-js`), sonner, lucide-react. Test: `node:test` (Node 22, tự bỏ kiểu TS) — **không thêm thư viện**.

**Spec:** `docs/superpowers/specs/2026-11-23-bao-gia-design.md`

## Review Focus

1. **Ô số để trống / gõ chữ vào ô số** (Excel ra 0đ sai): trống ⇒ qty/times = 1; đơn giá trống ⇒ "Theo thực tế", không cộng tổng; chữ/số âm từ API ⇒ null. → test ở Task 1 (`lineAmount`) và Task 3 (`sanitizeQuoteInput`).
2. **Rò thông tin nội bộ ra trang khách** khi điền từ kho: chỉ lấy giá gốc trước chiết khấu (`avgBase`, `getApplicablePrice`), không đọc `price_source`/`contract_summary`/`surcharge_note`. → test ở Task 4 (`buildStayItems` dùng base, `optionFromProduct` không mang trường nội bộ).
3. **Mở link báo giá trên host khách rồi gõ đường dẫn khác** (`/search`, `/api/search`, `/admin`): phải 404, không lộ trang nội bộ. → test ở Task 2 (`decideRoute`).
4. **Mã báo giá sai / đã xoá**: `/bg/<mã>` trả 404, không lỗi 500, không liệt kê báo giá khác. → bước kiểm tra ở Task 5.
5. **Báo giá rất dài khi in PDF** (5 phương án × 30 dòng, ghi chú dài): không cắt chữ, không tràn ngang, chi tiết phương án ≥2 bắt đầu trang mới. → bước kiểm tra in ở Task 5 với báo giá mẫu lớn.

```ts
//   → { option: ReturnType<typeof optionFromProduct>, items: QuoteItem[], rates: { id: string; label: string }[] }
```

Nếu > 1 mức giá, tên dòng thêm ` – đêm dd/mm, dd/mm`. qty_unit `"villa"` nếu `type === "villa"` ngược lại `"phòng"`.
  - không có ngày: 1 đêm, giá `price_weekday ?? price`, note `"Giá ngày thường (chưa chọn ngày)"`.
